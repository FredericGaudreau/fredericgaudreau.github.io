À propos

Ce site est une plateforme pour explorer et approfondir les langages HTML, CSS et JavaScript.

Qui suis-je ?

Je m'intéresse aux relations entre la technologie, l'être humain et son environnement. Passionné par le développement web et les outils qui améliorent la productivité, j'ai créé ces outils pour répondre à mes propres besoins tout en explorant les possibilités des technologies web modernes.

Les outils

Carte interactive

Créez et organisez des points d'intérêt en collections avec des couleurs personnalisées. Annotez chaque point avec des notes en Markdown. Consultez les informations locales (météo, altitude, qualité de l'air) pour chaque emplacement. Calculez des itinéraires entre vos points et partagez un point spécifique par un simple lien.

  • Organisation en collections
  • Notes Markdown par point
  • Informations météo et altitude
  • Calcul d'itinéraires
  • Partage par lien
  • Export JSON/CSV/Markdown
Notes Markdown

Un éditeur de notes Markdown avec aperçu en direct. Recherchez dans toutes vos notes, consultez des statistiques de lecture (nombre de caractères, mots, temps de lecture). Exportez vos notes en fichier .md ou sauvegardez l'ensemble en JSON.

  • Aperçu en direct
  • Recherche globale
  • Statistiques de lecture
  • Export .md et JSON
  • Intégration avec la carte
  • Mode plein écran

Technologies utilisées

Tout est construit en HTML, CSS et JavaScript vanilla, sans framework ni étape de construction. Les outils utilisent les API modernes du navigateur :

  • Stockage local : Vos données (points, collections, notes) restent dans le stockage local de votre navigateur
  • Service Worker : Le site est installable et fonctionne hors ligne
  • IndexedDB : Cache persistant pour les données géographiques
  • Geolocation API : Localisation de votre position
  • Fetch API : Récupération des données météo et géographiques
  • Leaflet.js : Bibliothèque de cartographie pour la carte interactive

Le rendu Markdown est assuré par un parseur maison, écrit sans dépendance et conçu pour échapper le HTML par défaut, assurant ainsi la sécurité.

Vie privée et sécurité

100% local, 100% privé

Aucune donnée ne quitte votre appareil. Tous vos points, collections et notes sont stockés uniquement dans votre navigateur. Vous gardez le contrôle total de vos données.

Le site fonctionne entièrement hors ligne une fois les ressources mises en cache. Vous pouvez l'installer comme une application progressive (PWA) pour un accès encore plus rapide.

Installation

Le site est conçu pour fonctionner comme une application web progressive (PWA). Vous pouvez l'installer sur votre appareil pour un accès hors ligne et une expérience similaire à une application native.

Sur mobile (Chrome, Edge, Samsung Internet) :

  1. Ouvrez le site dans votre navigateur
  2. Appuyez sur les trois points (menu) en haut à droite
  3. Sélectionnez "Ajouter à l'écran d'accueil" ou "Installer"
  4. Confirmez l'installation

Sur desktop (Chrome, Edge) :

  1. Ouvrez le site dans votre navigateur
  2. Cliquez sur l'icône d'installation dans la barre d'adresse ou sur les trois points (menu)
  3. Sélectionnez "Installer"
  4. Confirmez l'installation
